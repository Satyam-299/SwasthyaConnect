# SwasthyaConnect - Checkpoint 3

This directory contains the isolated files for Checkpoint 3: Email/Password Authentication UI.

## Files Included

- `app/layout.tsx`: A minimal root layout for Next.js.
- `app/login/user/page.tsx`: Renders the user login form.
- `app/signup/page.tsx`: Renders the user signup form.
- `lib/firebase.ts`: Firebase configuration and initialization.
- `src/components/UserLoginForm.tsx`: The UI component for the login form.
- `src/components/UserSignupForm.tsx`: The UI component for the signup form.

## How to Use

You can treat this directory as a minimal Next.js project. You can `cd` into it, initialize a Git repository, and push it to a specific branch on your GitHub account as outlined in your instructions.
